# Week 4 CRUD Todo API

A simple CRUD Todo API built with Node.js and Express.

## Features

- GET all todos
- GET todo by ID
- POST create a todo
- PATCH update a todo
- DELETE a todo

## Installation

```bash
npm install
```

## Run

```bash
npm start
```

Server runs on:

```
http://localhost:5000
```

## API Endpoints

GET /todos

GET /todos/:id

POST /todos

PATCH /todos/:id

DELETE /todos/:id
